# Banque de presets techno (branche `techno-presets`)

53 sons pour la techno, la hard techno, la techno industrielle, la hard trance et la hardtech, sur Skiff 2.7.
38 sont ajoutés en fin de liste de leur moteur ; 14 remplacent un preset « joli » au même numéro (liste en bas). Les
effets, le séquenceur, l'interface et les menus sont ceux de Skiff 2.7, octet pour octet : seules les tables de presets
changent.

**Préfixes :** LD lead · BS basse · PA pad · ST stab · DR drone / ambiance · FX effet · KT kit.
**Voix :** POLY = accords ; LEG = mono legato (glide sur les notes liées, comme les pas SLD du séquenceur) ;
UNI = mono, 8 voix empilées (chaque note prend 8 voix du budget : avec MENU > CPU 2 CORES, 16 voix au total, sinon 8
pour toutes les pistes ; quand il n'y a plus de place, l'unisson s'amincit au lieu de voler les autres pistes).
**Catégorie** = le filtre LIST de SAVE > PRESETS (BASS LEAD PAD KEYS PLUCK DRUM FX).
Les envois DIST / CHO / DLY / REV font partie du preset (avec MENU > KEEP SENDS ON, le chorus, le delay et la reverb
restent ceux de la piste).

remplacé : le nom affiché sur la piste d'un ancien projet, une étoile de favori, une entrée de SONG avec SET SOUND,
un Program Change MIDI.

## Revenir à Skiff 2.7 officiel

1. Sauvegarde ton projet avec l'éditeur web Skiff (onglet Backup).
2. Installe `skiff-2.7.fwsc` officiel (<https://github.com/illuminus5/skiff/releases/tag/v2.7>) avec l'installateur web
   de Skiff dans Chrome, ou `python3 tools/fm1_install.py skiff-2.7.fwsc`. Projets, presets utilisateur et réglages
   sont dans d'autres secteurs de la flash que l'application : ils devraient rester ; sinon, recharge la sauvegarde
   de l'étape 1.
3. En dernier recours (la FM-1 ne démarre plus) : restaure ta sauvegarde complète de la flash avec M-Flasher, ou
   suis la procédure de FM-1-transporter (<https://github.com/kurogedelic/FM-1-transporter>).

## Écouter les presets sans la machine

```
cc -O2 -w -Ibuild/gen -Ifirmware/src -o build/host/preset_bench tools/preset_bench.c -lm
build/host/preset_bench wav            # un WAV par preset LD BS PA ST DR FX KT, une phrase à 145 BPM
build/host/preset_bench wav BS         # seulement les basses
```
(après un `./build.sh`, qui génère `build/gen`)
